# Molecula

Учебное PWA-приложение по базовой химии.

## Идея

Пользователь выбирает атомы в периодической таблице. Приложение собирает выбранный состав, ищет известную молекулу в локальной базе знаний и показывает формулу, название и простую SVG-схему связей.

В режиме тренировки приложение задаёт цель, например «Собери воду», а пользователь должен выбрать два атома H и один атом O. Порядок выбора атомов значения не имеет.

## MVP

1. Периодическая таблица с интерактивными элементами.
2. Выбор атомов и отображение текущего состава.
3. Поиск молекулы по составу в локальной базе знаний.
4. Карточка результата: формула, название, простая SVG-схема.
5. Не менее 15 базовых молекул/веществ в knowledge base.
6. Режим тренировки «Собери молекулу».
7. Работа как PWA: installable + offline после первого открытия.
8. Адаптивный интерфейс для телефона, планшета и desktop.

## Технологический контур

- TypeScript
- React
- Vite
- SVG для визуализации молекул
- локальная knowledge base в JSON/TypeScript data modules
- PWA/service worker
- unit/component tests

Backend в MVP не используется.

## Архитектурный принцип

UI не должен напрямую зависеть от формата knowledge base.

```text
UI
 ↓
MoleculeEngine
 ↓
KnowledgeRepository

MoleculeEngine → MoleculeRenderer
```

Молекула моделируется как граф: атомы — вершины, химические связи — рёбра.
