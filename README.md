# Молекула

«Молекула» — полностью клиентское PWA для знакомства с составом простых веществ. В конструкторе можно выбирать атомы из периодической таблицы и находить известные составы, а в тренировке — собирать вещество по заданию. Порядок выбора атомов не влияет на результат.

Приложение не использует backend или runtime API. База веществ, интерфейс и SVG-схемы входят в сборку и доступны офлайн после первого успешного открытия.

## Требования

- Node.js 24.14.x (версия закреплена в `.nvmrc`);
- npm 11 или совместимая версия.

Если установлен `nvm`, выберите нужную версию Node.js:

```bash
nvm use
```

## Локальный запуск

Установите зависимости из lock-файла и запустите dev-сервер:

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес приложения в терминале. Dev-режим не предназначен для проверки service worker — для этого используйте production preview.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run format:check
npm run build
```

Для критических browser-сценариев используется Playwright. Перед первым запуском установите закреплённый Chromium:

```bash
npm run test:e2e:install
npm run test:e2e
```

E2E-набор автоматически собирает приложение, запускает production preview и проверяет desktop, планшетный viewport 768×1024 и мобильный viewport 360 px. Он покрывает конструктор H₂O, тренировку H₂O, клавиатурное управление, manifest и перезагрузку при отключённой сети.

Тот же набор статических, unit/component и browser-проверок запускается в GitHub Actions для каждого pull request и изменения `master`.

## Production-сборка

```bash
npm run build
npm run preview
```

Сборка появляется в `dist/`. Вместе с приложением генерируются `manifest.webmanifest`, `sw.js`, Workbox runtime и precache всех ресурсов application shell, включая локальную базу веществ.

## Ручная проверка PWA и офлайн-режима

Service worker работает только в production-сборке на `localhost` или HTTPS.

1. Выполните `npm run build` и `npm run preview`.
2. Откройте показанный Vite адрес в чистом профиле Chromium-браузера.
3. В DevTools → Application → Manifest убедитесь, что manifest загружен, а иконки 192×192, 512×512 и maskable распознаны.
4. В Application → Service Workers дождитесь статуса `activated and is running`.
5. Один раз откройте конструктор и тренировку при включённой сети.
6. В DevTools → Network выберите `Offline` и перезагрузите страницу.
7. Соберите H₂O в конструкторе, затем откройте тренировку и выполните задание с водой.

Оба режима должны работать без сетевых запросов. Автоматизированный эквивалент основной части сценария запускается командой `npm run test:e2e`.

## Иконки PWA

Исходники значка находятся в `public/molecula.svg` и `public/molecula-maskable.svg`. PNG-варианты воспроизводимо генерируются из них:

```bash
npm run generate:icons
```

Обычные иконки сохраняют скруглённый фон, а maskable-вариант держит знак внутри безопасной центральной области.

## Архитектура

- `src/ui` — React-компоненты и страницы;
- `src/application` — сценарии выбора атомов и тренировки;
- `src/domain` — типы и чистая химическая логика;
- `src/data` — локальная база веществ и репозиторий;
- `src/rendering` — универсальный SVG-рендерер молекулярных графов.

Подробные правила проекта находятся в [AGENTS.md](AGENTS.md), схема модулей — в [docs/architecture.md](docs/architecture.md), UX-направление — в [docs/ux.md](docs/ux.md).
